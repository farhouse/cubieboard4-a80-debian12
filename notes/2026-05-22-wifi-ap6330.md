# WiFi AP6330 funcional

Fecha: 2026-05-22

## Resumen

Se resolvió el error `sunxi-mmc 1c10000.mmc: fatal err update clk timeout` y `brcmfmac_sdio_htclk: HT Avail timeout`.

## Causa raíz

El DTS ya estaba correcto (mmc1 como SDIO 4-bit). El problema era doble:

1. **DTS**: Faltaban `post-power-on-delay-ms`, `no-1-8-v`, `reg_ldoio0` (AXP GPIO0) y drive-strength muy alto.
2. **Firmware**: No existían los firmwares del AP6330 en `/lib/firmware/brcm/`.

## Cambios en DTS

```dts
&wifi_pwrseq {
    post-power-on-delay-ms = <50>;
};

&mmc1 {
    no-1-8-v;
};

&mmc1_pins {
    drive-strength = <0x14>;  // antes 0x1e
};

reg_ldoio0: ldoio0 {
    // AXP GPIO0 como LDOIO0 (wifi_power_ext2 del FEX vendor)
    gpio = <&axp_gpio 0 GPIO_ACTIVE_HIGH>;
};
```

## Firmware instalado

```
/lib/firmware/brcm/
├── brcmfmac4330-sdio.bin  (fw_bcm40183b2_ag.bin, 239507 bytes)
└── brcmfmac4330-sdio.txt  (nvram_ap6330.txt)
```
